# 打包、运行与数据

## 运行（源码）

```bash
pip install -r requirements.txt
python main.py
```

依赖：requests、lxml、pywebview、pillow（图标生成）、pyinstaller（打包）。

## 打包

双击 `build_exe.bat`，核心命令：

```
pyinstaller --noconfirm --clean --onefile --windowed --name NCEPU教务助手 ^
  --add-data "web;web" ^
  --add-data "icon.ico;." ^
  --icon icon.ico ^
  --hidden-import webview.platforms.edgechromium ^
  --hidden-import clr_loader ^
  --hidden-import pythonnet ^
  main.py
```

产物：`dist\NCEPU教务助手.exe`（约 30MB）。打包后必须**实测启动**（进程存活数秒即通过）。

## 数据存储

数据在**程序目录下的 `data\`**（源码运行是项目下，打包后是 exe 旁边）：

| 文件 | 内容 |
|---|---|
| `data.db` | SQLite kv：课表/成绩/考试缓存、`remember`（记住密码勾选状态）、`about_hidden`（弹窗不再显示） |
| `cookies.json` | 登录 cookie + 用户名 |
| `account.json` | 勾选“记住账号密码”时保存的账号密码（**明文**） |

旧版数据在 `C:\Users\你的用户名\.ncepu_jwc\`，首次运行新版会自动迁移。

## 清理规则（重要）

- 勾选“记住账号密码”→ 退出登录/关闭窗口**保留**账号密码
- 未勾选 → 退出登录/关闭窗口**删除**账号密码（关窗时还会清 cookie）
- `cleanup_on_close()` 在 `main.py` 的 `webview.start()` 返回后调用

## 安全与发布

- 密码明文存本地，默认不勾选“记住账号密码”
- 需要 WebView2（Win10/11 自带）
- **发给别人前删掉 `dist\data`**，避免泄露自己的登录信息
- 弹窗“创建人/联系方式”目前是占位符，在 `web/app.js` 顶部 `APP_INFO` 修改，改后需重新打包
- 单文件 exe 可能被杀毒软件误报，加白名单即可
- exe 不要放 `C:\Program Files` 等受保护目录

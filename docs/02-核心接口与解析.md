# 核心接口与解析

所有请求都基于 `requests.Session` 维持 cookie（JSESSIONID / SERVERID）。学校站点仅校园网可达。

## 1. 登录

### 第一步：获取加密种子

```
POST https://jwxt.ncepu.edu.cn/Logon.do?method=logon&flag=sess
（无 body）
```

返回一段字符串（加密种子）。这是**检查/取种子**请求，不是提交账号密码。

### 第二步：生成 encoded 并登录

```
POST https://jwxt.ncepu.edu.cn/Logon.do?method=logon
body: userAccount=学号&userPassword=密码&RANDOMCODE=&encoded=...
```

`encoded` 算法（强智通用，实现在 `client.py::_make_encoded`）：

```
data_str 按分隔符（# 或 ; 或 |）切成 scode 和 sxh
code = 学号 + "%%%" + 密码
for i in range(len(code)):
    n = int(sxh[i])
    encoded += code[i] + scode[:n]
    scode = scode[n:]
```

登录成功标志：能打开 `xsMain.jsp` 且 URL 不含 `Logon.do`。

## 2. 学期 / 周次

- `get_current_term()`：从多个页面文本里找 `2025-2026-2` 这种格式（兼容“2025-2026学年第二学期”），页面顺序：`xsMain_new.jsp` → `xsMain.jsp` → `kbxx/jsjy_query` → `xsks/xsksap_query`
- `get_semester_info()`：返回 `(当前周, 总周数)`，从主页 `id="li_showWeek"` 元素解析，结构形如 `<span>第16周</span>/26周`；取不到则回退整页文本
- `get_current_week()`：同上取当前周

## 3. 课表（重要：按日期查询）

```
POST https://jwxt.ncepu.edu.cn/jsxsd/framework/main_index_loadkb.jsp
body: rq=YYYY-MM-DD
headers: Referer: .../xsMain_new.jsp, X-Requested-With: XMLHttpRequest
```

服务器根据日期自己算第几周，**不要传周次参数**。

解析（`_table_rows` / `_cell_info`）：
- 返回 HTML 表格，取行数最多的表
- 课程单元格的可见文本被截断（如“算法设计与分..”），完整信息在单元格内子元素 `<p title="课程学分：3&lt;br/&gt;课程属性：必修&lt;br/&gt;课程名称：...&lt;br/&gt;上课时间：...&lt;br/&gt;上课地点：...">`
- 解析出结构化 `{name, location, attr, credits}`

## 4. 课程成绩

```
POST https://jwxt.ncepu.edu.cn/jsxsd/kscj/cjcx_list
body: kksj=&kcxz=&kcmc=&xsfs=all
headers: Referer: .../kscj/cjcx_query
```

返回 HTML 表格。实际表头示例：
`['序号','开课学期','课程编号','课程名称','成绩','成绩标识','学分','总学时','绩点','补重学期','考核方式','考试性质','课程属性','课程性质','通选课类别']`

前端只显示 6 列：序号 / 开课学期 / 课程名称 / 成绩 / 课程属性 / 学分；筛选、排序、平均学分绩都在前端 `app.js` 完成（优=95、良=85、中=75、及格=65、不及格=55）。

## 5. 考试安排

```
POST https://jwxt.ncepu.edu.cn/jsxsd/xsks/xsksap_list
body: xqlbmc=&xnxqid=2025-2026-2&kc=&ksjs=&jkls=
headers: Referer: .../xsks/xsksap_query
```

实际表头：`['序号','考试类型','课程编号','课程名称','考试时间','考试地点','任课/负责老师','主监考','说明','座位号']`

前端显示 6 列（序号/考试类型/课程名称/考试时间/考试地点/任课老师），并按考试时间判断“已考完”（解析结束时间，`Date.now()` 比较）整行置灰。

## 6. 空闲教室

### 教学楼列表

```
GET https://jwxt.ncepu.edu.cn/jsxsd/kbxx/jsjy_processAjax?xqid=1|2&requestType=jxl
```

返回 JSON（可能是 rows 列表、映射等结构），解析成 `[(id, 名称)]`。二校区按固定顺序排列：教十一楼（默认）→ 教九楼B座 → 教十楼B座 → 教八楼B座 → 其他。

### 查询空闲教室

```
POST https://jwxt.ncepu.edu.cn/jsxsd/kbxx/jsjy_query2
body: typewhere=jszq&xnxqh=2025-2026-2&xqbh=2&jxqbh=&jxlbh=24&jsbh=&bjfh=%3D&rnrs=&jszt=8&zc=1&zc2=1&xq=1&xq2=1&jc=01&jc2=04&jsjylx=
```

参数说明：`xqbh` 校区编号（1/2）、`jxlbh` 教学楼编号、`jszt=8`（空闲状态，不要改）、`zc/zc2` 周次范围、`xq/xq2` 星期范围（1-7）、`jc/jc2` 节次（两位数字 "01".."10"）、`bjfh=%3D`（即 "="，requests 会自动编码）。

返回格式是**网格表**：表头如 `['星期','星期一']`，后续每行**第一个格子**是教室名（带 `(容纳/座位)` 后缀），其余格子为空。解析时取每行第一格并去掉括号数字。

## 7. 用户信息

`get_user_info()` 抓首页 `xsMain.jsp`（及 `xsMain_new.jsp`）文本，正则提取：
- 学号：`学生编号` 或 `学号` 后的数字串（学号 = 账号 = 学生编号）
- 姓名：`欢迎...同学` 或 `姓名/学生姓名`
- 班级：`班级名称` 或 `班级`

前端对学号有兜底：解析不到时直接用登录账号显示。

## 调试手段

- 各查询在控制台打印 `DEBUG xxx headers = ...`（表头）等
- 空闲教室会把返回页面存到 `~/.ncepu_jwc/classroom_debug.html`（注意：旧路径，打包版是 exe 旁 `data\`）
- 登录时打印 `DEBUG encoded = ...`，可与浏览器 F12 对比验证加密算法

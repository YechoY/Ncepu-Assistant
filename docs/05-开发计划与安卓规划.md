> 最后更新：2026-09-10。注意：本文件早期版本规划用 Capacitor 做安卓端，**实际安卓版已用 Flutter 实现**，据此更新。

## 双端架构（现状）

```
同一套需求，两端各自实现：
  ├─ Windows：pywebview + Python 后端（client.py / bridge.py），前端 Vue3（web/）
  └─ 安卓：Flutter（app/）——原生 HTTP、绕过浏览器 CORS，后端逻辑移植自 client.py
```

> 早期规划曾考虑用 **Capacitor** 复用 Vue 前端，后实际采用 **Flutter** 实现安卓版。
> 设计/计划见 `superpowers/specs/2026-08-21-华电教务助手-flutter-design.md` 与 `superpowers/plans/2026-08-21-华电教务助手-flutter-app.md`。

## 为什么手机端不能直接复用桌面版

1. **Python 无法在安卓原生运行**（BeeWare 等方案不成熟）
2. **浏览器 CORS**：纯网页版调学校接口会被拦截（VPN 也解决不了）
3. 教务系统仅校园网可达 → 后端逻辑必须**跑在手机本地**（App 自带）

## 安卓版要点（Flutter）

- 工程：`app/`（Flutter / Dart）；接口请求与解析移植自 `client.py`
- 网络：原生 HTTP（`http` 包），cookie 手动管理（JSESSIONID / SERVERID）
- 关键坑（详见 `03-踩坑记录.md` 与知识库 AI-Archive）：
  - release 连不上网 = 主 `AndroidManifest.xml` 缺 `INTERNET` 权限
  - 登录 302 必须用 GET 跟随
  - 模拟器跑 release 会因 ARM 翻译导致 Dart VM 快照加载失败（真机正常）
- 打包：`flutter build apk --release --target-platform android-arm64`

# 开发计划与安卓规划

## 当前状态

- ✅ Windows 桌面版功能完成：登录、课表、成绩、考试、空闲教室、缓存、记住密码、启动弹窗、图标
- ✅ 打包实测通过（单 exe，约 30MB）
- ⏳ 弹窗创建人/联系方式为占位符，待用户提供真实信息
- ⏳ 用户主要想在手机使用 → 规划安卓 APK

## 为什么手机端不能直接复用现状

1. **Python 无法在安卓原生运行**（BeeWare 等方案不成熟）
2. **浏览器 CORS**：纯网页版调学校接口会被拦截（VPN 也解决不了）
3. 教务系统仅校园网可达：手机需挂 VPN 才能访问，因此后端必须**跑在手机本地**（App 自带）

## 安卓方案（推荐：Capacitor）

```
同一份 Vue 前端（web/）
  ├─ Windows：pywebview + Python 后端（现状，不动）
  └─ 安卓：Capacitor 壳 + JS 后端（api.js，待移植）
```

### 要做的事

1. **定义接口契约**（已在 `01-架构与技术栈.md` 列出）：前端只调用统一方法
2. **写 `api.js`**（JS 版后端，翻译自 `client.py`/`storage.py`/`bridge.py`）：
   - 登录：`flag=sess` 取种子 → encoded 算法 → 登录
   - 课表/成绩/考试/空闲教室：请求 + `DOMParser` 解析（对应 `_table_rows`/`_cell_info`/`_classroom_names` 等）
   - 缓存：localStorage 或 Capacitor Preferences（对应 `storage.py`）
   - 网络：Capacitor 原生 HTTP（`@capacitor/core` 的 `CapacitorHttp`）绕过 CORS；cookie 手动管理（JSESSIONID/SERVERID 存请求头）
3. **前端切换**：`app.js` 顶部判断 `window.pywebview` 是否存在，存在走桥，否则走 `api.js`
4. **Capacitor 工程**：`npm` 初始化 → `@capacitor/core` / `@capacitor/cli` / `@capacitor/android` → `capacitor.config.json` → 把 `web/` 作为资源
5. **出 APK**：需要电脑安装 Android Studio（含 SDK/Gradle），`npx cap add android && npx cap open android` 构建
6. iOS：需要一台 Mac（Xcode），代码同源

## 不做的事

- ❌ 不用 Flutter / React Native（现有 Vue 作废，重写 UI）
- ❌ 不搞云服务器中转（服务器不在校园网，连不上教务系统）
- ❌ 不做 PWA 主方案（CORS 卡死）

- 每次改动建议跑：`py_compile` 全部 Python + `node --check web/app.js`

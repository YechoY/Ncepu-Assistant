# NCEPU 教务助手 — 开发文档

面向后续开发者的快速入门文档。本项目是一个 Windows 桌面工具（规划扩展到安卓），用于登录华北电力大学教务系统，查询**课表、课程成绩、考试安排、空闲教室**，数据本地缓存、离线可用。

## 快速了解

- **技术栈**：Python（后端）+ pywebview（桌面壳）+ Vue 3（前端）+ PyInstaller（打包）
- **运行**：`python main.py`（需校园网才能登录和刷新，离线可看缓存）
- **打包**：双击 `build_exe.bat`，产物在 `dist\NCEPU教务助手.exe`（单个 exe，约 30MB）
- **数据**：程序目录下 `data\` 文件夹（打包后为 exe 旁边的 `data\`）
- **界面**：Vue 3 前端在 `web\` 目录（vue.global.prod.js 已下载到本地，离线可用）

## 当前功能清单

- **登录**：无验证码，强智教务加密算法（先取加密种子，再生成 encoded）
- **课表**：按日期查询（服务器自己算第几周）、上周/下周切换、课程卡片独立配色、自定义日历（左右箭头切月）
- **课程成绩**：只显示 6 列（序号/开课学期/课程名称/成绩/课程属性/学分）；筛选（学期、课程名模糊、课程属性）；排序（学期/成绩/学分）；平均学分绩精确到 6 位小数
- **考试安排**：6 列展示，已考完的考试整行置灰
- **空闲教室**：校区/教学楼/星期/节次/周次条件；按当前时间自动选节次；条件变化（400ms 防抖）自动查询；结果每行 3 个教室卡片
- **启动弹窗**：关于信息（创建人/联系方式，占位符待填）+“不再显示”选项
- **记住账号密码**：勾选状态持久化；勾选时退出/关闭保留账号密码，未勾选时退出/关闭删除
- **本地缓存**：课表/成绩/考试数据离线可看；旧版本数据（`~/.ncepu_jwc`）自动迁移

## 常见命令

```bash
# 源码运行（Windows 桌面）
python main.py

# 打包
build_exe.bat

# 语法检查
python -c "import py_compile; [py_compile.compile(f, doraise=True) for f in ['main.py','bridge.py','client.py','storage.py']]"
node --check web/app.js
```

> 教务系统仅校园网可达；新界面依赖系统 WebView2（Win10/11 一般自带）。

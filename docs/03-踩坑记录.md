# 踩坑记录（按模块）

> 这些坑都真实发生过并已解决，后续改动请避免回退。

## 登录

1. **`flag=sess` 不是登录请求**：它是取加密种子的；真正登录是带 `userAccount/userPassword/RANDOMCODE/encoded` 的 POST。一开始理解成登录接口会走弯路。
2. **encoded 算法分隔符不唯一**：种子字符串可能是 `#`/`;`/`|` 分隔，解析时逐个尝试；`sxh` 逐字符转数字，超出长度时按 0 处理。
3. **测试中文乱码**：PowerShell 管道传中文给 Python 时控制台显示会乱码，属于测试通道问题，不是程序问题；验证中文解析时用 UTF-8 文件 + 纯 ASCII 断言。

## 课表

4. **课表接口不是按周次查的**：最初按强智通用地址 `xskb/xskb_list.do` 传 `zc` 周次参数，结果永远返回第 1 周。真实接口是 `main_index_loadkb.jsp`，**只传日期 `rq=YYYY-MM-DD`**，服务器自己算周。
5. **周次输入无效**：因为服务器忽略 `zc`，界面上“按周次查询”完全无效，最终移除，改成“按日期查询 + 上周/下周按钮”。
6. **课程名被截断**：可见文本“算法设计与分..”，完整名称在**子元素 `<p>` 的 `title` 属性**里（不是 `<td>` 的 title），且是多行结构（`课程名称：...<br/>上课地点：...`），需要解析 `title` 里的键值。
7. **合并单元格导致行单元格数不一致**：`_table_rows` 会得到长短不齐的行，处理时用 `any(cells)` 过滤空行，取格子按索引取值要判空。

## 本地缓存 / 多线程

8. **SQLite 跨线程报错**：`sqlite3.ProgrammingError: SQLite objects created in a thread can only be used in that same thread`。原因是一个连接在后台线程创建、界面线程使用。解决：**每次操作单独开连接**（`storage.py` 里 `_connect()` 每次新建并 `close`）。
9. **tkinter lambda 闭包 NameError**：`lambda: on_error(e)` 在 except 块外执行时 `e` 已被删除。解决：`lambda e=e: ...` 用默认参数捕获。

## pywebview / 打包

10. **`window.pywebview.api` 未就绪**：js_api 注入是异步的，页面 mounted 时可能还没有，导致“无法连接桌面后端”。解决：监听 `pywebviewready` 事件 + 轮询兜底（约 7.5 秒超时）。
11. **pywebview 6 的 `create_window` 没有 `icon` 参数**：传了 `icon=` 会 `TypeError` 导致 exe 启动即崩溃。exe 图标用 PyInstaller `--icon` 嵌入即可。
12. **PyInstaller 打包 pywebview**：必须加 `--hidden-import webview.platforms.edgechromium`、`--hidden-import clr_loader`、`--hidden-import pythonnet`，并且 `--add-data "web;web"` 把前端打进去；onefile 运行时资源在 `_MEIPASS`，用 `sys._MEIPASS` 定位。
13. **单文件 exe 首次启动慢**：正常现象（解压开销）。

## 空闲教室

14. **`jszt=8` 是空闲状态参数**，不要改成别的值。
15. **节次只有 1-10 节**（下拉范围 1-10，节次参数两位数字 `01`..`10`）。
16. **返回是网格格式**：表头 `星期/星期一`，每行第一格是“教室名(容纳/座位)”；不是“教室名称”列。解析取 `row[0]` 并去掉 `(数字/数字)` 后缀。
17. **教学楼编号映射**：教学楼下拉显示楼名、查询时传楼号（`jxlbh`）；`normalize_buildings` 兼容大小写键、`jsid/jsmc`、`{楼号:楼名}` 映射等结构。
18. **教室结果滚动**：Canvas 组件默认不响应鼠标滚轮，需要给画布和子元素绑 `<MouseWheel>`（新版网页端由 CSS 原生滚动解决）。

## 前端（Vue）

19. **原生日期选择器不可定制**：`<input type="date">` 的日历样式、上/下月按钮方向、“清除/今天”按钮都无法改，最终自绘日历组件（左右箭头 ◀▶、无清除/今天、点日期自动查询）。
20. **课程配色**：用课程名字符串哈希取固定色板（8 种柔和色），保证同一门课颜色稳定。
21. **成绩排序**：表头点击切换 ▲/▼，空值排最后；开课学期用 `localeCompare` 排字符串。
22. **“平均学分绩”精确到 6 位小数**，且用户明确不要“平均学分绩点”。

## 用户行为 / 需求变更（重要约定）

23. **启动总是显示登录页**，不自动登录；只有勾选“记住账号密码”才预填。
24. **记住密码勾选状态持久化**（存 `data.db`），勾上后下次启动仍勾选。
25. **退出登录只回登录页**，不退出软件；勾选记住密码时退出/关闭保留账号密码，未勾选时退出/关闭删除。
26. **“学号 = 账号 = 学生编号”**（首页 `xsMain.jsp`），侧边栏显示姓名/学号/班级，不再单独显示账号。
27. **空闲教室打开页面不自动查询**，只有条件变化才查（400ms 防抖）；打开时按当前时间自动选节次（8:00/10:00/14:30/16:10 分界）。
28. **数据存相对路径**（exe 旁 `data\`），旧数据从 `~/.ncepu_jwc` 迁移；发别人前要清空 `dist\data`。

## 环境

29. 本机 shell 沙箱有时无法启动，需在沙箱外执行（仅开发环境问题）。
30. 学校站点只能校园网访问，开发环境直接抓不到页面，需要用户提供抓包数据或让用户在校园网实测。

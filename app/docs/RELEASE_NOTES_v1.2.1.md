# 掌上华电 v1.2.1 — 饮水协议修复 + 一键取水 + 全局调试日志

## 🚨 必读：饮水取水失效修复

> 如果你之前遇到过「能看设备列表但点启动取水返回 code=-1」，**必须退出饮水登录后重新登录一次**才能生效。这是一次服务端版本门槛升级导致的协议修复。

## 🌟 新特性

- **饮水一键取水快捷卡片**：饮水首页底部固定入口，长按选择常用水设备后，点按即可启动 / 关闭取水授权；本地乐观状态即时反馈（蓝色 = 空闲，橙红 = 取水中），无需等待服务端轮询
- **饮水顶栏账户胶囊**：原 logout 图标升级为账户信息胶囊（👤 138****1234 ▾），点击弹出账户卡片展示头像、手机号、UID 和退出登录按钮；手机号持久化恢复，旧 Token 兼容显示 UID 后 4 位
- **全局调试日志体系**：
  - 首页模块导航页新增调试开关（橙色开启 / 灰色关闭），默认关闭、持久化保存、关闭时零开销
  - 日志查看页：按类型着色的时间线（HTTP 请求 / 业务层返回 / 错误自动标红），带滚动进度条，与首页开关双向同步
  - 饮水侧自动记录业务层错误码（如 -52 欠费、-88 未签约代扣等），不再只有 HTTP 状态码
  - 一键导出：直接写入系统 Download 目录，文件名带时间戳，用文件管理器即可找到
- **饮水设备状态胶囊徽章**：设备列表卡片和一键取水按钮右侧统一色点 + 底色 + 白字徽章样式，三态颜色对齐（空闲柔绿 / 使用中水滴蓝 / 离线雾灰）

## ⚡ 修复与优化

- **饮水 VersionCode 版本校验（核心修复）**：服务端单方面升级了 `/api/v1/dev/start` 端点的最低版本门槛（原 3.1.4 已低于新门槛 8.x），导致启动取水被拒但设备列表 / 状态 / 账单全部正常——这就是之前"能看不能取"的根因；现已对齐当前真机可用协议（UA `Android_ilife798_8.2.9` + VersionCode `8.2.9`）
- **教室查询框布局修复**：原 Wrap 流式布局在屏幕宽度变化时出现控件换行错乱，改为固定三行 Row + Expanded 等分布局，查询框不再错位
- **一键取水按钮设备名截断**：按钮内 Expanded 与 Spacer 平分剩余空间导致长设备名（如"华二13舍-112"）被截断，去掉 Spacer 让 Expanded 独占空间
- **Secure Storage Key 修复**：饮水 API 客户端常量缺失 `_kPrefix` 导致 IDE 爆红，改用四个独立常量 `_kToken / _kUid / _kEid / _kPhone`
- **调试日志导出链路收敛**：file_picker（需 compileSdk 36）、share_plus（需 android-33）、open_filex（被番茄小说等默认应用接管）均废弃，最终用 path_provider 直接写 Download 目录 + GlassSnackBar 提示路径

## 🔒 安全与架构

- 饮水协议参数完整对齐当前真机可用的 NcepuJw 参考项目：登录体 `openCode + un + authCode + cid`、启动取水 `ptype=91`、停止取水无额外参数
- 饮水模块物理隔离不变：独立 `HuishApiClient` + 独立 Riverpod `HuishAuthState` + `huish_` 前缀 Secure Storage Key

## 📦 兼容性

- Android 8.0+（minSdk 26）
- 仅 arm64-v8a 单架构包，安装包体积更小
- 学习服务需要校园网 / 校园VPN；生活饮水服务公网可直接使用

## 🔄 升级注意

1. **饮水用户必须重新登录**：退出饮水登录后重新进入，让服务端记录新的客户端身份（旧 Token 用低版本身份签发，服务端可能归类）
2. 学习服务账号不受影响，无需重新登录

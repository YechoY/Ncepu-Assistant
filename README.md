# 掌上华电 (Ncepu-Assistant)

华北电力大学教务系统的**非官方学生端**，由学生个人以 vibecoding 方式开发，仅供学习交流使用。

## 功能特性

- **课表**：周课表（自动定位今天、显示日期与节次时间、午休/晚课分隔线）+ 全部课表（整学期网格、备注展示）
- **成绩**：各学期成绩查询、必修平均学分绩自动计算、支持勾选课程自定义计算
- **考试安排**：时间/地点一览，未考/已考状态标识
- **空闲教室**：按楼栋/时段/周次查询空闲教室
- **浅色玻璃拟态 UI**：磨砂玻璃卡片、胶囊导航、统一弹窗体系
- **离线可用**：数据本地缓存，无校园网也能查看上次同步的课表与成绩
- **检查更新**：自动检测 GitHub Releases 上的新版本

## 下载安装

前往 [Releases](https://github.com/YechoY/Ncepu-Assistant/releases/latest) 页面下载最新 `app-release.apk`（arm64-v8a 架构），安装即可。

- 系统要求：Android 8.0+
- 使用需连接校园网或 VPN；首次安装需允许「安装未知应用」

## 自行构建

```bash
flutter pub get
flutter build apk --release --target-platform android-arm64
```

- Flutter 3.x / Dart ^3.13
- 产物位于 `build/app/outputs/flutter-apk/app-release.apk`

## 项目结构

```
lib/
├── app.dart              # 应用入口、主框架、检查更新
├── theme.dart            # 设计 token（色板、玻璃参数、动效曲线）
├── pages/                # 登录、课表、成绩、考试、教室等页面
├── providers/            # Riverpod 状态管理（认证/数据/离线缓存）
├── services/             # 教务系统 API 解析、本地缓存
└── widgets/              # 玻璃卡片、下拉、导航等通用组件
```

# 掌上华电 (Ncepu-Assistant)

华北电力大学（保定）的**非官方学生端**，Flutter 开发，由学生个人独立完成，仅供学习交流使用。

应用采用模块化架构，启动后进入模块导航页，两个服务各自独立登录、数据互不串通：

- **学习服务**：华电教务系统（学号 + 密码，需校园网）
- **生活服务**：惠生活 798 饮水（手机号 + 短信验证码，公网可用）

## 功能特性

### 学习服务（教务系统）

- **我的课表**：周课表自动定位今天，显示日期、节次时间、午休/晚课时段分隔线；支持左右切换周次与日历选周，顶部提示切换结果
- **全部课表**：整学期网格视图，上课地点、教师、备注完整展示
- **课程成绩**：各学期成绩查询，必修平均学分绩自动计算，支持勾选课程自定义计算
- **考试安排**：考试时间/地点一览，未考/已考状态标识
- **空闲教室**：按楼栋、时段、周次自定义查询
- **离线可用**：数据本地缓存，无校园网也能查看上次同步的课表、成绩与考试安排，离线时顶部显示提示条

### 生活服务（惠生活 798 饮水）

- **手机号登录**：图形验证码 + 短信验证码，登录态本地持久化
- **扫码取水**：扫码后直进取水页，手电筒开关，支持手动输入设备码
- **一键取水**：开始 / 结束取水一键切换，实时显示本次接水量与本次花费
- **我的设备**：设备自定义命名、分组管理（新建/重命名分组）、长按拖拽排序、从列表移除
- **消费记录**：账单明细与状态筛选（已付/未付），钱包余额展示

### 通用体验

- **浅色玻璃拟态 UI**：磨砂玻璃卡片、胶囊导航、统一玻璃弹窗与顶部提醒，整套自研设计 token
- **安全存储**：教务密码与饮水 token 均使用 `flutter_secure_storage` 存入 Android Keystore，不明文落盘
- **应用内更新**：自动检测 GitHub Releases 新版本，支持应用内下载（实时进度、取消、四重超时保护）、唤起系统安装器，并保留复制链接兜底

## 下载安装

前往 [Releases](https://github.com/YechoY/Ncepu-Assistant/releases/latest) 页面下载最新 APK（arm64-v8a 架构），安装即可。

- 系统要求：Android 8.0+
- 学习服务需连接校园网或校园 VPN；生活服务在公网环境即可使用
- 首次安装需允许「安装未知应用」

## 自行构建

```bash
flutter pub get
flutter build apk --release --target-platform android-arm64
```

- Flutter 3.x / Dart ^3.13
- 产物位于 `build/app/outputs/flutter-apk/app-release-arm64-v8a.apk`

## 项目结构

```
lib/
├── main.dart              # 应用入口
├── app.dart               # 主框架、路由、检查更新
├── theme.dart             # 设计 token（色板、玻璃参数、动效曲线）
├── pages/                 # 模块导航、登录、课表、成绩、考试、教室等页面
├── providers/             # Riverpod 状态管理（认证 / 数据 / 离线缓存）
├── services/              # 教务系统 API、会话管理、本地缓存
├── models/                # 课表、成绩、考试、教室等数据模型
├── widgets/               # 玻璃卡片、弹窗、导航、顶部提醒等通用组件
└── huish/                 # 生活服务（惠生活 798 饮水）独立模块
    ├── huish_api_client.dart  # 饮水接口（token 独立安全存储）
    ├── huish_auth_state.dart   # 独立登录态
    ├── sign_utils.dart         # 接口签名工具
    ├── device_prefs.dart       # 设备名 / 分组本地偏好
    └── *_page.dart             # 登录、首页、取水、账单、添加设备页面
```

# NCEPU 教务助手

一个简单的 Windows 桌面小工具：登录学校教务系统后查看**课表**、**课程成绩**、**考试安排**，并支持**空闲教室查询**。数据会缓存在本地，不在校园网时也能看到上次抓到的课表和成绩，连上校园网后自动刷新。

界面采用 **Vue 3 + pywebview** 构建（前端代码在 `web\` 目录），打包后仍是单个 exe，界面离线可用。

## 给同学的使用说明

1. **环境要求**：Windows 10 / 11（需要系统自带的 WebView2，一般都有）。
2. **运行**：双击 `NCEPU教务助手.exe` 即可（开发调试用 `python main.py`）。
3. **必须连接校园网**才能登录和刷新数据；不在校园网时只能查看上次的缓存数据。
4. **数据存在哪**：exe 旁边的 `data\` 文件夹（课表/成绩/考试缓存、cookie、记住的账号密码）。
5. **“记住账号密码”默认不勾选**，勾选状态会保留（下次打开仍是勾选状态）；勾选后密码以明文保存在 `data\account.json`，仅建议在自己电脑上使用。
6. **请勿高频刷新**，避免给学校服务器造成压力。
7. 提示“连接超时/无法连接”时：先确认已连接校园网，再检查账号密码是否正确。

## 运行方式（开发调试）

```bash
pip install -r requirements.txt
python main.py
```

## 打包成 exe

双击 `build_exe.bat`，完成后在 `dist\NCEPU教务助手.exe`。打包出来是**单个 exe**，双击即可运行；数据会自动保存在 exe 旁边的 `data` 文件夹里。建议把 exe 放在普通可写目录（比如桌面或自己的文件夹），不要放 `C:\Program Files` 这类需要管理员权限的位置。

> 运行新版需要系统自带的 WebView2 运行时（Win10/Win11 一般都有，Edge 浏览器即基于它）。

## 本地数据存在哪里

程序目录下的 `data\` 文件夹（源码运行是项目下的 `data\`，打包后是 exe 旁边的 `data\`）：

- `data.db`：课表、成绩的本地缓存（SQLite）
- `cookies.json`：登录后的 cookie（不含明文密码）
- `account.json`：勾选了“记住账号密码”时保存的账号密码（**明文**，仅建议个人电脑使用）

> 旧版本数据在 `C:\Users\你的用户名\.ncepu_jwc\`，首次运行新版时会自动搬过来。

## 安全提示

- 登录页的“记住账号密码”**默认不勾选**，勾选状态会保留；勾选后会把密码以明文存在 `data\account.json`，退出登录/关闭窗口时会保留；**未勾选**时，退出登录和关闭窗口都会删除本地保存的账号密码。
- 请只用于个人查询，不要高频刷新，避免给学校服务器造成压力。

## 待确认事项（需要你在校园网环境下抓包补全）

1. **登录加密**：程序按“强智教务通用算法”实现（先取 `flag=sess` 的加密种子，再生成 `encoded`）。登录时控制台会打印 `DEBUG encoded = ...`，请你和浏览器 F12 中真正登录请求里的 `encoded` 对比。如果不一致，把登录页引用的 JS 文件（类似 `conwork.js`）或登录请求的完整表单发给我。
2. **空闲教室查询参数**：教学楼列表已经能用（`requestType=jxl`），但“查询某栋楼某时间空闲教室”的真实参数还需要抓包确认。在浏览器里选好教学楼、周次、星期、节次后点查询，把那个请求的地址和表单抓给我，我改 `client.py` 里的 `get_free_classrooms`。
3. **按日期查课表**：已改用你们学校主页的真实课表接口 `jsxsd/framework/main_index_loadkb.jsp`（POST `rq=日期`，服务器自己算第几周）。日期通过弹窗日历选择（带“今天”快捷按钮），选完自动查询；课表页左侧会显示当前第几周/共几周。如果课表解析不对，把主页课表区域的 HTML 结构发我看一下。

## 常见问题

- **必须在校园网环境下才能登录和刷新**：程序启动时会检测能否连上学校网站，连不上就只显示本地缓存。
- **登录失败提示“账号或密码错误”**：先确认账号密码没问题，再看上面第 1 条的 `encoded` 对比。
- 请只用于个人查询，不要高频刷新，避免给学校服务器造成压力。
